# PTIA-lab02: Redes Neuronales

Este repositorio contiene la solución al Laboratorio 02 de la asignatura **Principios y Tecnologías de Inteligencia Artifical (PTIA)**

## Autores
- Andrés Cardozo
- María Paula Rodríguez

## Contenido del Repositorio

- `RN-lab-andrescardozo-mariarmunoz.ipynb`: Notebook principal donde se implementan y exploran conceptos de Redes Neuronales (Deep Learning), incluyendo la creación de modelos multicapa (Dense), aplicación de funciones de activación, cálculo de métricas de desempeño y costo, empleando librerías como TensorFlow/Keras, Pandas y NumPy.
- `BEED_Data.csv`: Dataset utilizado para el entrenamiento, validación y prueba técnica del modelo de red neuronal.
